# استاندارد آپلود بازی — نسخه ۱.۰

این سند قرارداد فنی «بسته بازی» است؛ اعتبارسنجی ماشینی (`ZipGamePackageValidator`) دقیقاً همین قواعد را چک می‌کند. رعایت آن = تأیید سریع‌تر توسط ادمین.

## ۱) ساختار بسته

```text
my-game.zip
├── index.html          ← الزامی، در ریشه
├── js/  css/  assets/  ← مسیرهای نسبی
└── ...
```

- قالب: **ZIP** — حداکثر **۵۰ مگابایت فشرده** و **۳۰۰ مگابایت نافشرده**
- حداکثر **۳۰۰۰ فایل**
- نقطه شروع بازی فقط `index.html` در ریشه بسته است
- همه مسیرها **نسبی** باشند؛ مسیر مطلق و `../` (zip-slip) رد می‌شود
- پوشه‌های زائد (`__MACOSX`, `.DS_Store`, `._*`, `Thumbs.db`) نادیده گرفته می‌شوند

## ۲) پسوندهای مجاز (whitelist)

| دسته | پسوندها |
|---|---|
| سند/داده | html, htm, css, js, mjs, json, txt, csv, xml, md |
| تصویر | png, jpg, jpeg, gif, webp, svg, ico, bmp |
| فونت | woff, woff2, ttf, otf |
| صدا/ویدیو | mp3, ogg, wav, m4a, mp4, webm |
| موتورها | atlas, tmx, tmj, fnt, bin, pak |

فایل‌های اجرایی (exe, dll, bat, cmd, sh, ps1, msi, so, dylib, php, aspx, jar) **کاملاً ممنوع** و باعث رد خودکار می‌شوند.

## ۳) محیط اجرا (sandbox)

بازی در iframe با این sandbox اجرا می‌شود (امنیت پلتفرم — قابل مذاکره نیست):

```html
<iframe sandbox="allow-scripts allow-pointer-lock allow-popups allow-modals allow-forms">
```

- **بدون `allow-same-origin`**: یعنی `localStorage`/`document.cookie` در دسترس نیستند. این الگوی ایمن را بگذارید:

```js
const store = {
  get(k){ try { return localStorage.getItem(k); } catch(e){ return null; } },
  set(k,v){ try { localStorage.setItem(k,v); } catch(e){} }
};
```

- درخواست‌های شبکه به دامنه خارجی توصیه نمی‌شود (بازی باید آفلاین کار کند)
- موبایل: بازی باید با لمس هم قابل بازی باشد (pointer events) و responsive باشد

## ۴) متادیتا

| فیلد | قاعده |
|---|---|
| عنوان | ۳ تا ۱۲۰ نویسه، فارسی خوانا با کلیدواژه واقعی (سئو) |
| توضیحات | حداقل ۲۰ نویسه |
| کاور | JPG/PNG/WebP ≤ ۲MB، نسبت ۳:۲ |
| تگ‌ها | با کاما؛ تگ مشترک با وبلاگ = نمایش در پست مرتبط |
| دسته | از فهرست: اکشن، معمایی، پازل، کازوال، استراتژی، ورزشی، خانوادگی، ماجراجویی، آموزشی |

## ۵) فرآیند بررسی

1. ارسال فرم `/games/submit` (نیاز به حساب کاربری)
2. اعتبارسنجی ماشینی — تخلف = رد با پیام دقیق، بدون ذخیره فایل
3. ورود به صف ادمین (نمایش در داشبورد)
4. تأیید → انتشار در کاتالوگ / رد → نمایش دلیل به شما
5. هر اقدام ادمین در Audit Log (با منبع Web یا MCP) ثبت می‌شود

محدودیت‌های شناخته‌شده فاز ۱: اسکن آنتی‌ویروس وجود ندارد (whitelist پسوندها جایگزین موقت است) — KI-4 در spec.
